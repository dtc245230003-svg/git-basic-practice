## 📦 Hướng dẫn cài đặt
1. Clone repository này về máy:
   ```bash
   git clone https://github.com
   ```
2. Di chuyển vào thư mục dự án:
   ```bash
   cd project-name
   ```
3. Cài đặt các gói phụ thuộc (dependencies):
   ```bash
   npm install
   ```
4. Chạy ứng dụng ở chế độ phát triển:
   ```bash
   npm run dev
   ```
